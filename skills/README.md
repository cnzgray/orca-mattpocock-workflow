# skills

The two intake skills that ship with the plugin. Orca plugins cannot register runtime skills, so the
bodies live here as files. After the user explicitly triggers "Install intake skills" in the panel,
they are copied into the skill directories agents scan:

- `~/.claude/skills`
- `~/.codex/skills`
- `~/.agents/skills`

Only existing directories are written: creating a new directory out of thin air does not make any
agent recognize it.

| Skill | Purpose |
| --- | --- |
| `mattwf-bug` | Turns a bug report into a raw ticket; files the ticket and does not classify it |
| `mattwf-feature` | Turns a requirement into a raw ticket; files the ticket and does not interview |

The bodies are generated by `src/worker/workflow-skills.ts` from the flow definitions in
`src/protocol/flow.ts` and the label mapping in `src/protocol/labels.ts`. `workflow-skills.test.ts`
checks that the checked-in `SKILL.md` files match the generated output; after changing a flow
definition, regenerate both files.

Skill bodies are always in Simplified Chinese: they are prompt content, not UI copy, and do not
follow the panel's `language` setting.
